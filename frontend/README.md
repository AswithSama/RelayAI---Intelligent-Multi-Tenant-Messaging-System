# AI Operations Playground — Frontend Milestone 1

Static React + TypeScript interface for an internal AI workflow testing environment.

## Included

- Fictional company workspace selector
- Empty conversation-message workspace
- Needs Review and Completed queue tabs
- One sample escalated workflow item
- One sample successfully processed workflow item
- Disabled message composer and Run AI controls for the static milestone
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally `http://localhost:5173`.

## Current behavior

Select **Northstar Home Services** to display the two static sample queue items. Other companies intentionally have empty queues. The frontend has no backend, database, or model connection yet.
